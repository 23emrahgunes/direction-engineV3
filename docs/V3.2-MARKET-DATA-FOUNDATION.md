# V3.2 Market-Data Foundation

V3.2 adds only credential-free, read-only public market-data boundaries. It does not
make strategy decisions or submit orders.

## Ownership

- `adapters`: public protocol URLs, subscriptions, strict untrusted-JSON parsing, and
  read-only HTTP/WebSocket transport.
- `market_data`: canonical immutable events, lineage, UTC/monotonic clocks, source
  health, freshness, bounded retry, sequence continuity, and bounded buffers.
- `domain`: stable market, token, asset, horizon, and outcome identity.

The root package still imports bootstrap configuration only, so importing
`direction_engine_v3` performs no network I/O.

## Sources

- Binance Spot and USD-M Futures public WebSocket feeds provide aggregate trades and
  depth events. V3 retains event time and update ranges; gaps require snapshot restore.
- Polymarket Gamma provides market/outcome/token identity and public resolution
  metadata. Outcome labels are explicitly associated with token IDs; list position is
  never interpreted without its paired label.
- Polymarket CLOB provides public books, market fee metadata, and market WebSocket
  subscriptions. Books use `Decimal`, canonical sorting, checksum identity, and source
  timestamps when the protocol supplies them.
- Polymarket RTDS publishes Chainlink 30/60-second crypto TWAP updates. V3 uses the E18
  `full_accuracy_value`, retains publisher and underlying source timestamps separately,
  and configures the documented five-second application heartbeat.

## Fail-closed behavior

- Missing, malformed, non-finite, mismatched-symbol, or ambiguous-outcome data raises a
  typed market-data error. Values are never fabricated or converted to zero.
- Connected is not equivalent to subscribed, and subscribed is not equivalent to
  fresh. Trading consumers must pass both source-event and transport-silence limits.
- Delta consumers cannot proceed before a snapshot. Gaps set `resync_required` and
  block further use until a new snapshot is restored.
- Buffers are bounded. Callers explicitly choose fail-closed overflow or latest-only
  replacement, whose drops are counted.
- Reconnects are bounded with exponential backoff and jitter and always resubscribe.
- Fee responses without a source timestamp record `source_ts=None`; receipt time is not
  misrepresented as a venue event time.
- Public resolution metadata is not treated as final settlement proof.

## Security boundary

The shared transport allowlists only documented public Binance, Polymarket, and RTDS
hosts, rejects embedded URL credentials, follows no redirects, exposes no POST method,
and requires an explicit async lifecycle. No secrets are used by tests or adapters.

## Test boundary

Deterministic fixtures cover normalization, exact decimals, outcome/token association,
timestamps, freshness failures, sequence gaps/resync, retry bounds, buffer overflow,
fee lineage, settlement-metadata semantics, source/symbol mismatches, and public
transport security. Controlled external smoke checks are acceptance-only and are not
part of the deterministic test suite.
