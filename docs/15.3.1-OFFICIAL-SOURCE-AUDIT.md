# V3.15.3.1 Official Source Audit

V3.15.3.1 adds a read-only official-source audit before any bounded PTB wait.
The committed contract remains PAPER/SHADOW-only and does not enable LIVE,
signing, authenticated order submission, or real Polymarket orders.

## Runtime evidence commands

The user-context SSM bridge runs these commands on the VPS and writes sanitized
JSON under `runtime/reports/`:

- `python -m direction_engine_v3.diagnostics.official_source_audit`
- `python -m direction_engine_v3.diagnostics.rtds_probe`
- `python -m direction_engine_v3.diagnostics.binance_hourly_probe`

## Source-selection rule

Short-horizon PTB may be established only from the source proven by current
market rules and live RTDS evidence. If the live source shape is unsupported,
the phase must block with explicit evidence instead of guessing aliases or using
proxy/Binance/Polymarket book data.

For 1h buckets, the only official path is the Binance USDT 1h candle whose open
time exactly matches the current market `window_start`.

## WhaleSignal provenance

WhaleSignal `chainlink_feed.py` behavior is used only as migration provenance
for websocket lifecycle, PING/PONG, reconnect/backoff, timestamped history, and
boundary lookup. V3.15.3.1 does not bulk-copy WhaleSignal architecture, topic
semantics, or credentials.
