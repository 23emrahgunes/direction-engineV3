## Runtime changes

V3.15.3 ports proven WhaleSignal feed behavior into V3 owners without bulk-copying legacy
architecture:

- Chainlink official runtime uses the existing V3 60-second RTDS TWAP subscription/parser only.
- Per-asset Chainlink state tracks latest 60s TWAP, source timestamps, bounded history, reconnects,
  last message time, and last transport/protocol error.
- Binance 1h official runtime is separate from Binance proxy depth/trade data and accepts only the
  exact canonical 1h candle open.
- PTB resolution restores persisted boundary-proven records first and otherwise establishes PTB only
  from valid boundary evidence.
- Missing boundary evidence remains fail-closed as `PTB_UNAVAILABLE`; no current quote, proxy,
  Polymarket book, zero/default, or fabricated value can create PTB.
- Directional shadow evaluation now receives real PTB/features/pricing when available and advances to
  `MODEL_UNAVAILABLE`/`CALIBRATION_NOT_READY` instead of remaining stuck at
  `OFFICIAL_PTB_UNAVAILABLE`.
